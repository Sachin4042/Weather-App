# Weather-App

A responsive weather application built using HTML, CSS, Bootstrap, and JavaScript that provides real-time weather information for any city using the WeatherAPI service.

## Features

- Search weather by city name
- Display current temperature in Celsius
- Show weather condition and icon
- Display humidity and wind speed
- Responsive and user-friendly interface
- Real-time weather data using WeatherAPI

## Technologies Used

- HTML5
- CSS3
- Bootstrap 5
- JavaScript (ES6)
- WeatherAPI

## How It Works

1. Enter a city name in the search box.
2. Click the Search button.
3. The application fetches weather data from WeatherAPI.
4. Current weather details are displayed instantly.

## API Used

WeatherAPI:
https://www.weatherapi.com/
